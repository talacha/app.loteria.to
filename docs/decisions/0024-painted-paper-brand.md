# 0024. Painted ribbon identity and paper background

- **Status:** Accepted
- **Date:** 2026-10-27

## Decision

At the owner's request, use an original hand-painted arched ribbon logo and a rugged paper page texture. The logo appears prominently on Home and compactly in the interior header, with accessible naming. The texture blends with the existing light/dark theme background; high-contrast mode remains plain.

Generated assets are local WebP files and use the existing static deployment/cache pipeline. The reference decks inform the medium and ribbon motif, without incorporating their artwork or trademarks. [Production prompts](../design/painted-brand.md) document the built-in imagegen workflow.

This release changes branding only. The in-progress expanded catalog and remaining card wiring are a separate release.
