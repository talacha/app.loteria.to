# 0021. No "hide the picture" practice mode in v1.0

- **Status:** Accepted
- **Date:** 2026-10-27

## Context

A per-player "Practicar de oído" toggle that hides the picture was discussed. It is not in [rules.md](../rules.md) and not built.

## Decision

- v1.0 has no listening-only mode. Every card shows its picture; the pick is the language exercise ([0004](0004-rules-spelling-picks-points-full-card.md)).
- Copy must not advertise one (backlog BUG-004).

## Consequences

- A future toggle would need a rules.md change first (per player, off by default, cartón never hidden).
